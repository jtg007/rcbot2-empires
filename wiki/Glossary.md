# Glossary

Sources: [README.md](../README.md), [AGENTS.md](../AGENTS.md), [docs/OPEN_WORK.md](../docs/OPEN_WORK.md), `reverse-engineering/notes/vehicle-driving.md`, code comments.

| Term | Meaning |
|---|---|
| Empires | Source mod mixing FPS and RTS; two teams, one commander each |
| NF | Northern Faction, team 2 (`emp_info_player_nf`, `NF_*` vehicles) |
| BE | Brenodi Empire, team 3 (game internal prefix "Imperial": `Imperial_APC`, `emp_info_player_imp`) |
| CV | Command Vehicle: the commander's vehicle (seat role 1 = commander, role 0 = driver) |
| VF | Vehicle Factory (building type 5, needs research) |
| APC | Armored personnel carrier; with research `APC_Spawn_Point` it is a mobile spawn |
| AFV | BE light tank chassis (`Imperial_AFV`); NF counterpart is the Light Tank |
| HU | Hammer unit (Source length unit) |
| Navmesh | Source navigation mesh `empires/maps/<map>.nav`, generated by `p_nav_generate` |
| Recorder | Passive analysis recorder (`rcbot_analysis_*`) |
| Team director | Per-team situation board that assigns push/hold/defense roles and alerts |
| Commander orders | Game order types: 0 abort, 1 move, 2 attack location, 3 attack target, 4 guard |
| EngiBot | Buyable base-engineer bot for human commanders (`/buildengibot`) |
| Lawliet | Desperation APC rush on the enemy CV when a team falls behind (item 5.14b) |
| Bill Nye | Scout jeep ramming enemy vehicles, rainbowroad (item 3.6b) |
| Kill-spawn | Tactical respawn by `kill` at a spawn much closer to the goal (item 5.28) |
| Skirmish | Close-quarters infantry movement module `bot_empires_skirmish.cpp` (item 3.25) |
| Pad | Repair pad / repair station building; vehicles repair and refit there |
| Physbox | `emp_building_vehicle_physbox`: invisible collision proxy of buildings for vehicles; also bounces grenades |
| Wages | Per-player money from rank points; vehicle purchases spend wages first |
| `stall-escalate` | Log line every escalation step writes: `who=... stage=... reason=...` |
| `dev-runs` | Run folders in the test server: `YYYYMMDD-HHMMSS-<map>-<bots>b-<min>m` |
| Item IDs | Stable work-item IDs used in commits, logs and `docs/OPEN_WORK.md`: `1.x` commander/economy, `3.x` vehicles/navigation/combat, `5.x` features and acceptance, `6.x` cleanup, `7.x` human checks (grouping inferred from the list) |
| Expert / tester | Optional Claude Code agents in `.claude/agents/` (`expert.md`: strong model for root cause; `tester.md`: small model for runs) |
